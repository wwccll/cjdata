# 成交数据管理

房产成交数据自动收录工具，支持手机+电脑多端互通。

## 使用方法

1. 粘贴「成交播报」文本到输入框
2. 点击「解析并录入」或按 Ctrl+Enter
3. 数据自动同步到 Supabase 云端数据库
4. 手机/电脑打开同一个网址即可共享数据

## 云同步原理

```
手机 ──→ Supabase 云数据库 ←── 电脑
  ↑                              ↑
  └──── 同一个网址，数据互通 ─────┘
```

## 部署

本项目通过 Vercel 部署，绑定 GitHub 仓库自动更新。

## 技术栈

- 前端：原生 HTML/CSS/JS
- 数据库：Supabase (PostgreSQL)
- 部署：Vercel
